# Iteration 0: the Game of Life

Run of the O2 register (`notes/CASES.md`) under `.cells/EXPERT-SYSTEM.md`.
Evaluator: script, `tools/gol/`. Rerun: `python3 tools/gol/run.py`.

## Predictions

Committed before any code ran.

### Set-up

A board of 128 × 128 cells, wrapping, run for 120 steps. An occurrence is a
cell at a step, alive or dead. A tracing is a proposed continuity: its live
cells at every step. All occurrences in one tracing are one class; every other
occurrence is a class of its own. Checks 1–3 run on these classes against
*same cell*. Only a pair that passes them reaches the candidates. Each candidate
judges each step of the tracing, carried or not; the tracing holds when every
step is carried.

### Candidates as computed

- **Closure.** Delete everything but the tracing's cells, run the rule one
  step. Carried when the result equals the tracing's next cells.
- **C1, film map.** One map, the same at every place and step, sends each
  frame's shape to the next frame's shape and offset. A step is carried when
  it agrees with what the map does elsewhere in the tracing. Reads the history
  only.
- **C2, activity filter (stand-in).** Active cells: those that change at that
  step. A step is carried when the two frames are joined through active cells
  that touch, across the two steps.
- **C7, viability (stand-in).** Closure, and the actual cells around the
  tracing match the undisturbed run: the surroundings leave it alone.
- **C8, shortcut.** The tracing splits into periodic segments (same shape
  every p ≤ 8 steps, fixed shift). Carried when it needs at most K segments.
  Run with K = 1 and K = 2: the bound is a free parameter.
