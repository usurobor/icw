# Iteration 0: the Game of Life

Run of the O2 register (`notes/CASES.md`) under `.cells/EXPERT-SYSTEM.md`.
Evaluator: script, `tools/gol/`. Rerun: `python3 tools/gol/run.py`.

## Predictions

Committed before any code ran.

### Set-up

A board of 128 × 128 cells, wrapping, run for 120 steps. An occurrence is a
cell at a step, alive or dead. A tracing is a proposed continuity: its live
cells at every step. All occurrences in one tracing are one class; every other
occurrence is a class of its own. Checks 1–3 run on these classes against
*same cell*. Only a pair that passes them reaches the candidates. Each candidate
judges each step of the tracing, carried or not; the tracing holds when every
step is carried.

### Candidates as computed

- **Closure.** Delete everything but the tracing's cells, run the rule one
  step. Carried when the result equals the tracing's next cells.
- **C1, film map.** One map, the same at every place and step, sends each
  frame's shape to the next frame's shape and offset. A step is carried when
  it agrees with what the map does elsewhere in the tracing. Reads the history
  only.
- **C2, activity filter (stand-in).** Active cells: those that change at that
  step. A step is carried when the two frames are joined through active cells
  that touch, across the two steps.
- **C7, viability (stand-in).** Closure, and the actual cells around the
  tracing match the undisturbed run: the surroundings leave it alone.
- **C8, shortcut.** The tracing splits into periodic segments (same shape
  every p ≤ 8 steps, fixed shift). Carried when it needs at most K segments.
  Run with K = 1 and K = 2: the bound is a free parameter.

### Case fixes after the first run

Two cases were built wrong the first time; both builds stay in the table.

- **Cyclic splice.** Meant as a regular jump. The row of 8 gliders wraps back
  from the last to the first, so one jump differs from the rest and C1 refused
  it for that reason. Added the alternating splice (A, B, A, B), where every
  jump from a given phase is the same move.
- **Collision.** The first placement annihilates: glider and block vanish, and
  the tracing goes empty, so C2's break came from the empty frames. Added a
  placement that leaves debris to follow.

With the fixed builds, every mark matches the prediction.

## Findings

1. **Closure and C7 match every target and agree on every case,** as
   predicted. They should separate under noise.
2. **Reading the history fails.** C1 uses one uniform map over the frames and
   accepts the alternating splice. It refuses splices only where a glider phase
   recurs; frames that never recur (the reaction, debris) it always accepts.
   This is the executable case for R1 as amended: carrying is read off the
   rule.
3. **Adjacency fails.** C2 joins frames through touching activity, so it
   accepts the indirect splice and the glider-into-debris collision.
4. **C8 is not a criterion yet.** Its verdict on the splice and the
   step-indexed grouping flips with K, and at K = 1 it still accepts the
   cyclic and alternating splices.
5. **Closure cuts at joins.** In the indirect splice it carries glider A, then
   the reaction as one whole, then glider B, and breaks at the two joins
   (steps 56–57 and 72). After a collision it carries the debris as a new
   continuity. Owner question: is the reaction a carried whole?
6. **Empty frames.** Closure carries an empty tracing (nothing evolves to
   nothing). A continuity needs a footprint; this belongs before check 4.
7. **Limits.** The cases were designed around the splice; closure here is
   exact, with no "mainly"; no noise; C2 and C7 are stand-ins.

## Corrections after review (16 Nov)

Reviewed by two models of other families after the run.

- **Names denote implementations.** C1 here checks consistency of observed
  shape-and-offset transitions; it is not Israeli and Goldenfeld's
  commutation, universal or under intervention. C2 checks connected activity;
  it builds no causal states. C7 is closure plus a local-surroundings check,
  not Beer's viability framework. Each mark is a result for that code, not for
  the theory it is named after.
- **Finding 2 is narrower than written.** The alternating splice defeats this
  history-based check. It does not show that every history-based criterion
  fails. Reading carrying off the rule is the owner's decision (R1), which the
  case illustrates.
- **Union of two distant gliders,** traced as one persistence: every
  candidate holds it, at every step, after passing checks 1–3. Added to the
  harness as a probe; the owner's target is unset. Any criterion built from
  local self-sufficiency is closed under disjoint union, so none of these can
  refuse a fusion.
