# C3: compression

Candidate C3 (`notes/CASES.md`). Source: Dennett, "Real Patterns", *J. Phil.*
88 (1991): a pattern is real when a description that uses it is more
efficient than the bit map. Rerun: `python3 tools/gol/c3.py`.

Compression is relative to a describer: to a compressor and to a format.
D9 excludes describer relativity, since an articulation is not an act of
description. C3 is run to see where that bites.

## Declared before any C3 code ran

### Description lengths

D(x) is the length in bits of the byte string x compressed by Python's
`lzma`, raw format (no container header), filter LZMA2, preset 9 with the
extreme flag. One compressor, fixed now.

- **Bit map:** the history H, every frame, every cell, one bit per cell
  (`numpy.packbits`, row-major). L_raw = D(bit map).
- **The tracing's description:** for each step in order, the number of
  footprint cells (2 bytes), the cells' positions relative to their bounding
  box corner (1 byte per coordinate, sorted), the corner's move from the last
  non-empty step (1 byte per coordinate, modulo the board side; the first
  corner absolute), and the cells' states at that step (packed bits). An
  empty step writes only the count 0. L_trace = D(that string).
- **Residual:** the bit map with every footprint cell set to 0 at its step.
  L_res = D(residual bit map).

**Gain** = L_raw − (L_trace + L_res), in bits. A positive gain means the
description that uses the tracing is shorter than the bit map: Dennett's
criterion read literally.

### Verdict

C3 judges a whole tracing, as C8 did in iteration 0: one flag per tracing.
The collision rows ask for a break at a step and are marked n/a, as for C8.

θ is the midpoint between the glider's gain (anchor+) and the splice's gain
(anchor−), computed first and written here before any other case is scored.
A tracing is carried when its gain is above θ. If the splice's gain is at or
above the glider's, no threshold separates the anchors, and that is the
result: θ is then reported and the grid still run at it. Sensitivity: θ
scaled by 0.8 and 1.2. Also reported: every verdict at the literal threshold
0.

### Probes

A probe part judged over an interval uses the tracing restricted to that
interval, with the full history in L_raw and L_res. Rule 184: the same
description with one coordinate.

### Rule 9

Checked by run, as in C11: board shifted 7 rows and 13 columns; 7 empty frames
before the history. Byte packing is not shift-invariant, so this check can
fail here. Gains under each shift reported.

## What this shows

1. **The anchors separate by their boards.** The glider anchor is alone on
   its board; the splice shares a board with a second glider. The same glider
   traced on a two-glider board gains 384 to 408 bits, near the splice's 296.
   The compressor reuses the other glider, so a tracing's gain depends on
   what else the board holds. θ = 744 sorts boards, and refuses two anchor+
   rows.
2. **On one board the order is right and the margins are small.** True
   trace 408, splice 296, alternating splice 104. A jump costs the describer
   about 100 bits. A space shift moves gains by up to 136 bits.
3. **The literal criterion holds the lookalikes.** At gain above 0 every
   splice except the cyclic one is a real pattern, as C-2 predicted. The
   union, the indirect splice and the debris collision gain the most of all:
   a tracing that covers more of the board leaves less residual.
4. **Short and irregular tracings lose.** Eleven steps of glider gain below
   0, so the probe parts before contact fail. The interaction, the eater, the
   jam and the car cost more to list than to leave in the bit map. A blinker
   (code test) also fails: the compressor finds its period in the bit map.
5. **Where D9 bites.** The verdict changes with the board's other contents,
   the tracing's length, the format and the shift. Each is a fact about the
   describer. None is read off the rule (R1).

## Status

C3 as run is out: 5 of 9 judged grid rows, 2 of 10 probe parts, and the rows
it gets right it gets by board contents. Compression marks the cost of a jump
on a fixed board; that cost is a describer's version of reach.
