# Audit 2026-11-16: rule 184 flow function and car identity

Claim under audit: number-conserving CA admit a local flow function; in rule 184 a car crosses i to i+1 iff i occupied and i+1 empty; flow unique once zero flow is fixed on the empty configuration; so car identity is recoverable from the transition function without extra notation. Sources named: Hattori-Takesue 1991, Boccara-Fukś 1998, Fukś 2000.

| 2 Rule 184 crossing rule | Supported. Boccara-Fukś motion representation gives rule 184 as one entry: a particle with an empty right neighbour moves right. Fukś: "Particles (cars) move to the right if their right neighbor site is empty." Moreira-Boccara-Goles also treat rule 184 as motion rule M4. | nlin/0501043; nlin/0207047; nlin/0306040 | Keep. |
| 3 "Unique once zero flow is fixed on the empty configuration" | No source states it. The true literature statement concerns the converse: Redeker finds flow determines f only for a minimal state set, otherwise "several different transition functions for the same flow function." Redeker fixes the base half-flow at zero, which fits the claim. The register's own run (script /tmp/aud/chk.py, 3-site windows): with phi(00)=0 the 2-site flow for rule 184 is forced, phi(10)=1 and phi(01)=phi(11)=0. Without that normalisation there are 4 solutions (a constant shift). | 1907.06063v4; own computation | Restate: "flow is unique up to an additive constant, fixed by phi(empty)=0; derived here, with Redeker as the nearest source." Tag as own derivation. |
| 4 Unique flow gives unique car identity | Partly. The flow is a net current, and the claim needs an order-preserving matching on top. For rule 184 the flow is in {0,1}, which fixes each car's move (stay or +1) and order. On rings the script confirmed the flow-induced matching is consistent on 3000 random 16-site rings. Fully packed ring: phi(11)=0 is forced, so the flow selects "all stay". The ambiguity the proposer saw (all stay vs all advance) disappears once the flow is used. For general number-conserving rules with flows beyond {0,1} the net flow underdetermines individual moves; order preservation is an added convention. Fukś: particle identity is rank in an increasing sequence, i.e. an added convention. He does not work out periodic rings. Moreira-Boccara-Goles: canonical PA "preserves particle order". | own computation; nlin/0207047; nlin/0306040 | Restrict to rule 184 or to flows in {0,1}. State order preservation as an assumption. |
| 5 Prior work: identity derived from the rule | Partial. Redeker cites Fukś for "one can assign permanent identities to the" particles and calls the follow-up question open. Moreira-Boccara-Goles: PA "do not distinguish particles"; tracking by order is suggested. Fukś's particle map is not unique (composition with a shift). No source claims identity is forced by the transition function alone. | 1907.06063v4; nlin/0306040; nlin/0207047 | The "without extra notation" wording overstates. Say: identity follows from the flow plus the order-preserving convention. |
| 6 Periodic and fully packed caveats | Boccara-Fukś show conservation can be tested on circular configurations of given size (Redeker summary). Fukś allows periodic site configurations but does not treat identity on rings. A global cycle (rotation) on a ring is a known caveat in Moreira-Boccara-Goles: a ring may carry a global cycle. The 107/3000 ambiguities for moves in {-1,0,+1} are consistent with this. | 1907.06063v4; nlin/0207047; nlin/0306040 | Keep the proposer's executable check as the support. No literature found on the fully packed ring specifically. |
