# Intent: README

What the ICW front page must achieve. Authored by the owner; skills and
cells answer to it. A judge tests output against this file only, never
against a skill.

| ID | Intent | Test the judge runs | Pass |
|---|---|---|---|
| R1 | Draws a stranger in | After paragraph one: "Would you read on? 1–5, and why." | ≥ 4 |
| R2 | Top-down: paragraph one alone gives the idea | Reader restates the idea from paragraph one only; compared with the reference answer | Matches reference |
| R3 | Clear to a smart non-specialist ("grandma") | Reader lists every term or sentence not understood | None in paragraph one; ≤ 2 in the README |
| R4 | Succinct | Word counts; "what could be cut without loss?" | ≤ 650 words; nothing essential flagged as cuttable |
| R5 (proposed) | Says why it matters | "Why would anyone care?" from paragraph one | A concrete answer, not a restatement |
| R6 (proposed) | True | Every claim checked against the kernel | No claim beyond the kernel |

## Reference answer for R2 (owner to approve)

> When something changes, there can be two honest ways to say what stays the
> same, like the wave versus the water. ICW gives a test for when both count,
> instead of arguing which is real.
